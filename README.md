# OOP Final Project - Employee Pass Slip System

## Setup (One time only)
1. `git clone https://github.com/Hexteriaxxxxx/OOP-Final-Project`
2. Open in IntelliJ
3. Add `lib/postgresql-42.7.3.jar` to Project Libraries
4. Run the project

## No database setup needed!
Database is hosted on Supabase (cloud) — works out of the box.

## To run visitor server:
Double-click `START_PUP_SYSTEM.bat`
